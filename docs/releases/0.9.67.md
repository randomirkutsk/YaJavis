## Поддержка Google Gemini по умолчанию

- **Google Gemini Live из коробки.** Голосовой движок по умолчанию переключен на Gemini Live с официальным голосом Charon.
- **Системный характер Джарвиса.** Обновлена системная инструкция под классического дворецкого J.A.R.V.I.S. (точность, краткость для устной речи, вежливость).
- **Поддержка Gemini в классическом режиме.** Добавлен вызов Gemini API при отсутствии OpenAI ключа.
- **Оптимизация для Станции Миди (Cucumber).** Подтверждена совместимость перехвата микрофона VQE и ARM64 бинарников.
